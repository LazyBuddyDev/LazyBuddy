# UI 规范

本文件是宿主界面外观与公共交互的权威说明，适用于现有和后续所有功能。按界面职责、能力与状态描述规则，不按具体功能页分别定义样式。开发与文档总则见 [AGENTS.md](../AGENTS.md)，页面生命周期见[架构](architecture.md)，API 与诊断边界见[宿主模块契约](module-api.md)。业务专属语义由所属服务文档说明，当前未完成任务的进度和必要验收证据归 [TASKS.md](../TASKS.md)，完成后删除，不保留任务归档。

## 复用原则

- 新界面先匹配已有模式，再复用公共样式和控件；同一种交互只能有一套视觉规则。不能按功能复制页签、工具栏、开关、图标或底部提示样式。
- 公共样式归宿主样式表，功能作用域只补充必要的内容布局；不能用功能名选择器或窄窗口覆盖恢复另一套公共控件风格。
- 所有滚动区域的滚动条常态隐藏，仅鼠标悬停到对应区域时显示；统一使用公共细滚动条样式，不在功能内永久隐藏。预留滚动条宽度，显隐不改变内容布局，隐藏时仍支持滚轮、触控板及键盘滚动。
- 外层页面滚动容器预留滚动条时，两侧使用对称滚动槽（`stable both-edges`），使内容区和工具栏保持居中；不得在功能页用负边距抵消公共滚动槽。
- 共享实现可以是一段样式、模板或现有组件，不为简单复用额外引入框架。业务回调和数据归所属功能，共用外观不意味着共用请求状态。
- 数值均为 CSS 逻辑像素，随 DPI 正常缩放，不照搬示意图的位图像素。下表是当前基线；调整时同步公共实现与本规范，不在调用处复制数值。

| 模式 | 当前基线 | 状态与布局要求 |
| --- | --- | --- |
| 顶部工具栏 | 浅色主题 `#153f32`，深色主题 `#102f27`；浅色前景 | 与内容区分隔；选中、悬停和键盘焦点可辨 |
| 工具栏图标按钮 | 常规 34×34；窄窗口 28×30 | 图标居中，按钮组对齐，不因状态改变尺寸 |

| 选择与范围输入 | 下拉框128×30；滑杆128×20 | 统一主题边框、表面色、文字及强调色；保留原生键盘操作和清晰焦点 |

| 数据源标题栏 | 最小高度 43；标识 23×23；左侧色条宽 3 | 标题字号 13、适度加粗，操作按钮不被长标题挤走 |

## 主题、字体与形状

- 使用系统界面字体和公共字号层级，不引入远程字体、图标字体或运行时图片转换。小窗口优先信息密度，标题层级通过字重、间距和标识建立，不靠各处任意放大字号。
- 页面背景、内容表面、正文、次级文字、边线和强调色复用宿主主题变量。浅色、深色、背景透明度与卡片透明度须同时考虑，不能把整页背景或正文硬编码为白色。
- 主窗口和主要容器保持直角。小型选择器可保留既有轻微圆角；开关、圆形滑块及贴边收起态使用各自固定形状，不扩散成其他卡片的新圆角风格。
- 透明窗口内的曲面向内预留1逻辑像素，避免抗锯齿边缘落在原生硬裁剪线上；外轮廓使用1逻辑像素中性边线，悬停不改变轮廓颜色，键盘焦点以内描边表示，不改变控件尺寸。
- 自绘透明表面不叠加系统的非客户区激活/失焦描边，仍保留系统焦点事件。窗口尺寸变化先于前端状态切换时，小型控件保持固定逻辑尺寸，不随临时视口拉伸。
- 颜色不能是唯一的识别手段：选中还应有形状或填充变化，来源还应有标识与名称，异常应有可读文字。

## 公共焦点提示

- 窗口统一由 `focusNavigation` 记录输入方式：Tab/Shift+Tab进入键盘导航，鼠标或触控指针按下切回指针模式；方向键、回车、空格及文本输入只操作当前控件，不自行改变导航方式。组件不得复制输入方式监听或另设焦点体系。
- 指针模式下不显示额外焦点外框，避免点击后再按方向键出现整页或整控件的意外边框。键盘导航保留2逻辑像素强调色焦点轮廓，默认外偏移3；可裁剪表面和圆形入口复用 `.focus-inset`，内偏移-2。
- 输入框保留光标、选择范围及所属输入容器的编辑态边框，包裹输入框不重复绘制内层轮廓。焦点、开关选中、当前页签/条目、忙碌和错误是独立状态；统一焦点外观不能删除这些状态或妨碍快捷键录入。
- 依赖键盘焦点的附加展示遵循同一导航方式；指针悬停保持原行为。监听只处理外观，不阻止默认操作或传播，并在所属窗口销毁时释放。

## 窗口与公共外壳

- 主窗口固定分为顶部工具栏、可伸缩内容区、底部信息栏。标题与全局入口归工具栏，加载、安装、账号处理与运行错误归底部信息栏，不能随内容滚动或重复放进页面卡片。
- 顶部显示既有产品标识、产品名、根页面选择和全局操作。根页面通过统一入口切换；功能管理、设置等属于平级页面，返回当前根页面，不形成额外导航栈。
- 置顶使用斜向图钉，功能管理使用四宫格，设置使用齿轮；这些入口仅显示图标，必须有明确的可访问名称和悬停提示。置顶和当前打开的全局页面保留选中反馈。
- 固定操作图标统一经公共图标组件使用已有 SVG 资源；平台标识通过公共映射选择本地资源。不能用字符、表情或各页自制图形替代同一个公共操作的图标。
- 工具栏所有非交互区域，包括空白、内边距和标识区域，均可拖动窗口。按钮、选择器等控件优先处理事件，不能为了拖动吞掉其点击或键盘操作。
- 关闭按钮、Alt+F4 和原生关闭请求统一隐藏到托盘；明确退出才结束进程。主窗口不创建任务栏按钮，保留托盘入口，工具栏不提供独立最小化按钮。系统最小化、隐藏与恢复遵守同一内容静默规则，恢复不自动播放媒体。
- 双击托盘图标或选择托盘菜单的“显示”时，恢复窗口并将其激活到最前面，保留原有永久置顶选择；托盘单击仅显示窗口。
- 贴边收起态仅显示约 40 逻辑像素的产品标识和圆形边框，原生命中区域同样裁圆；恢复保留尺寸、有效位置、页面、滚动和置顶选择。收起不是新建一个内容页面。
- 贴边收起态不参与系统贴靠排列，关闭原生缩放与最大化能力；展开时恢复原有能力，不修改用户的系统窗口设置。
- 收起态支持拖动，移动达到4逻辑像素后进入原生窗口拖动，松手吸附当前显示器最近的左右侧边并保持收起；展开位于新的停靠侧和高度。拖动结束不触发点击展开，普通点击和键盘展开仍有效，内容页面在拖动期间保持静默。

## 页签与内容工具栏

- 所有内容页及其专属设置共用 `.feature-page` 内边距、`.tab-bar` 分隔线与 `.tabs` 按钮；内容最大宽度1160，常规内边距12×14，宽度不超过600时为10；分隔线紧接页签栏底部，下方间距12，切换页签不改变位置。选中实心、未选中透明，字号和间距一致；不混用下划线式、链接式或每个功能单独一套的页签。
- 页签栏只承载页签。检索、筛选、视图切换和刷新放在其下方独立工具栏，不能因某个页签多一个按钮而改变页签栏高度。
- 同类集合共用工具栏与结果模板：输入区在左并可伸缩，视图切换位于主操作左侧，主操作在右。主操作根据能力执行检索或刷新，名称与图标必须说明真实动作。
- 检索输入通过明确提交或回车执行；本地筛选只过滤已确认的数据。不能为保持外观一致把本地筛选变成联网请求。
- 各集合分别保留输入内容、列表／网格选择及滚动位置。重复选择当前页签或仅切换视图，不应重新检索或全量刷新。

## 聚合卡片与条目

- 数据源使用“本地平台标识＋淡色标题栏＋左侧短色条”辨识；同一平台的不同榜单或分组通过副标题区分，不随机更换字号和正文底色。
- 平台色只用于标题区域。当前标题混色比例为浅色主题 9%、深色主题 15%，正文沿用公共表面色；数据源色与标识在一个公共映射中维护，未知来源使用默认标识和中性色。
- 平台标识随宿主打包，不为显示标题额外发起网络请求。引入资源必须核对来源、许可和实际编码，并将所需许可带入安装包。
- 标题右侧的关注和刷新是独立操作。星标采用五角星，已选中为黄色实心、未选中为空心；一次操作只改变对应按钮的状态，不让其他条目或全部刷新一起闪烁、禁用或重排。
- 卡片标题固定，条目列表独立滚动并预留滚动条位置。卡片与文本容器允许收缩，操作按钮和徽标不能被长文本挤出；滚动不串到相邻卡片。
- 正文采用紧凑行距，前三排名可使用红／橙色，其余使用次级文字色，不添加密集行分隔线。排名和顺序来自当前数据，不能仅为装饰伪造。
- 超长条目标题默认截断，保留全文提示；鼠标悬停或键盘聚焦时仅对溢出文字向左滚动，离开复位。非活动页面不运行该动画，系统要求减少动态效果时停用。
- 服务端提供的条目标签显示为紧凑徽标；缺失或无法识别时不创建占位。标签紧随可见标题，不固定占用每行同一块空白。

## 集合、标记与展示资源

- 列表和网格是同一结果集的两种视图，共用条目顺序、操作、确认状态与观看等真实进度。网格每格由封面、名称和必要状态构成，不另造一套业务数据。
- 标记状态在列表、网格和详情／媒体视图间一致。乐观反馈与服务端确认分离，失败或取消回滚，写入期间禁止重复提交；无记录与已确认记录明确区分。
- 已成功读取的远端集合保留，重复进入不自动刷新。首次读取、用户手动刷新或核对已提交写入结果时才请求；失败保留已确认内容，账号切换清除旧展示。
- 封面按可见区域懒加载，离页取消排队和后续派发。失败显示有界占位；用户刷新成功后允许失败项重新加载，不把失败当作永久的“没有封面”。
- 缓存按集合的实际需求选择，不因复用网格模板就给所有检索结果增加专属持久缓存。不同视图的缓存边界必须明确；服务重建不能让已有有效像素缓存仅因内存来源表丢失而不可读。不得为缓存保存签名地址、凭据或其他秘密。

## 设置、快捷键与操作状态

- 各内容页在既有页签中提供独立“设置”，只调整当前能力的偏好；齿轮只打开宿主通用设置，不混入专属分类。只影响当前内容的外观偏好归专属设置，不能改变其他内容的表面。设置保留根页面切换入口及各自展示状态；返回当前根页面，切换内容保持全局分类。
- 页签以 `aria-pressed` 表达选中状态，开关和页签均提供说明用途的悬停提示；危险操作使用浅深主题各自的语义色。
- 布尔设置统一复用公共开关及 `setting-row` 布局，不新增原生复选框或各页自制开关；保留 `role=switch`、可访问名称、键盘和禁用反馈。
- 全局快捷键通过“点击按钮后按键录入”修改，不使用要求用户手写组合键的输入框。录入状态清晰可见，Esc 取消，Tab、失焦、离页与隐藏结束捕获，保存失败不能伪装成已修改。
- 设置区使用预留布局宽度的滚动条，不让悬浮滚动条遮挡按钮或文字，也不嵌套重复的垂直滚动容器。窄窗口下可将条目操作独立成行，不能为修复公共框架顺带重排业务内容。
- 加载、选中、悬停、禁用与错误均需清晰但克制。异步操作的忙碌状态绑定发起操作及请求代数；界面只合并结果，不在事件处理过程中执行同步持久化或重任务。

## 提醒标记

- 提醒统一使用公共红色圆点，不显示数量、不闪烁、不改变控件尺寸；浅深主题及窄窗口保持可辨，提供可访问的提醒原因。标记不能代替忙碌、失败或操作结果。
- 来源声明稳定事件ID、修订标识和展示入口，入口只负责聚合与确认。鼠标移入或键盘聚焦时确认该入口当前承载的未读快照；触摸进入、隐藏或收起状态不确认。父入口确认当前聚合事件，子入口同步消除；子入口确认只影响对应事件。交互期间新到的修订不被旧快照确认。
- 已读状态按事件及修订持久化，保存失败恢复未读并给出提示；打开页面、安装状态变化及读取失败不能被当成确认动作。新修订再次提醒，消除标记不执行更新、安装或其他业务操作。
- 提醒发现属于所属能力的调度边界；宿主管理检查不能唤醒静默内容页。失败保留已确认数据，不以失败或未完成准备的状态生成新提醒。

## 能力管理列表

- 可安装能力只维护一份列表，合并可信目录与已安装记录，不将共享运行时展示为独立业务入口。
- 每行左侧显示名称和当前版本；已安装项右侧提供更新／卸载，未安装项提供安装。没有新版本或目录不可用时禁用更新，离线仍可卸载已安装项。
- 列表标题同一行右侧提供返回按钮，与再次点击对应全局入口共用导航，回到当前根页面内容。安装与更新进度放在操作所属条目的名称和按钮之间；下载按包含缺失依赖的实际字节显示，准备、校验及安装显示不定进度。结果与错误仍归固定信息栏。

## 媒体视图

- 所有视频播放页统一复用 `MediaControls.svelte` 及公共媒体样式：顶部从左到右为返回、可截断标题、实际可用的集合操作；暂停或失败时画面中央为播放／重试。底部第一行为全宽进度条，第二行依次为上一项、播放／暂停、下一项、当前位置／总时长、伸缩间隔、选集、实际可用清晰度、倍速及音量。不可用的相邻项保留位置并禁用；没有实际能力的集合操作、选集或清晰度不生成占位控件。
- 控制组件只维护展示与拖动预览，账号、媒体会话、业务请求、播放偏好及生命周期仍归所属功能。更换标题、控制显隐、切换菜单和调整窗口不能触发业务请求。窄窗口允许公共控制区换行，顺序保持一致，进度、播放及音量入口不能被标题挤出。

- 控件覆盖媒体，悬停或 Tab 聚焦时显示，离开隐藏；菜单打开期间保持显示，选择、取消或离页清理菜单状态。控件、浮层和窗口尺寸变化不得改变媒体尺寸、重建播放管线或重新取源。
- 左键点击画面切换播放／暂停，控制按钮只执行自身动作，不冒泡导致二次切换。空格同样切换，画面聚焦后 Enter 也可操作，左右键跳转 5 秒；输入框、下拉框、可编辑区域和快捷键录入优先处理按键。
- 右键按住 400ms 临时 2 倍速，松开恢复用户所选倍速且不额外跳转；失焦、暂停、隐藏、离页和换条目均清理按住状态。
- 媒体页面复用公共音量控件和样式，保持各自独立的播放偏好与生命周期。悬停静音按钮或键盘聚焦时，在按钮上方显示竖向音量条及百分比。鼠标能连续移入浮层，拖动实时调整当前媒体音量；窄窗口不可直接隐藏调音入口。
- ↑／↓ 每次调节 5%，范围 0–100%；输入等控件优先，不修改系统音量。音量与用户明确选择的静音分别保存，调到零或调高不能暗中改写静音选择。
- 清晰度是用户偏好，按当前媒体实际可用能力选择；不足偏好时使用最高兼容档位，界面显示实际档位，保留偏好供后续条目使用。不为降档额外循环请求，不把声明档位当成实际解码尺寸。
- 进度拖动只预览、松手提交一次，键盘及滚轮操作仍正常提交；暂停、离页清理预览，不让旧管线的零值覆盖目标位置。加载中禁止重复打开；失败在画面中央提供“重试播放”图标按钮，保留条目、位置和用户偏好，仅明确点击后重新取源。

- 启用连续播放预加载的媒体能力，只能在当前内容真实播放后异步准备已确认可用的紧邻下一项；同时最多保留一个候选和有界内存首段，不提前播放、标记已观看或上传候选进度。仅真实结束事件推进；隐藏、离页、换内容或参数不匹配时取消并隔离迟到结果，恢复不自播或自动重启准备。准备失败不打断当前项，不自动循环请求或绕过来源拒绝。预加载属于业务服务能力，不通过额外隐藏播放器或公共控制组件取源。

## 底部提示与诊断入口

- 底部信息栏保持固定位置，摘要可截断，长详情点击展开并在栏内有界滚动。日志、更新等按钮等高且不随正文滚动。
- 功能提示只属于当前根页面及对应专属设置，切换后清除原功能提示，迟到消息不得串入其他页面或覆盖全局管理操作。账号提示不能出现在无关内容页。
- 错误摘要给出可读原因；详情包含阶段、操作上下文及处理入口。错误码用于分类，不能代替原因，也不能把尚未定位的上游问题写成已修复。
- 日志入口是宿主通用入口，打开统一日志目录，不按当前功能更换目录。服务返回脱敏 API 诊断，由宿主记录异常；格式、归档与数据白名单只在[宿主模块契约](module-api.md#宿主日志与服务诊断)维护。

## 长文本书页导航

- 具备书页导航的阅读视图支持水平翻页、垂直翻页和连续滚动，模式在所属设置中选择并持久化；默认水平翻页。书页按实际正文区域、字号和行距排版，内部传输分块不作为用户导航层级。
- ←/→分别向前/向后移动一页，页首/页尾按阅读顺序衔接相邻章节；保留具备可访问名称、悬停提示和忙碌状态的上一页/下一页按钮。文本输入、选择、非翻页按钮、可编辑区域、修饰键及快捷键录入优先，不拦截其方向键。
- 分页模式下，章内与跨章翻页共用方向、240ms时长和 `cubic-bezier(.2,.8,.2,1)` 缓动；连续滚动的按页导航不附加平移动画。新章准备好前保留当前画面，平移时只暂存一个不可交互的旧页快照，结束或取消后立即释放；过渡保留正文键盘焦点，并以 `aria-busy` / `aria-disabled` 及内部操作锁表达忙碌，不因翻页将整组按钮置灰或移出焦点顺序；真实首尾边界等不可用状态仍使用原生禁用。隐藏、切页或窗口重排打断过渡时保留原稳定阅读位置，不能提前提交尚未展示的新章进度。
- 分页模式中滚轮驱动整页切换；连续模式保留自然滚动并按可视高度翻页。平移动画尊重减少动态效果设置，重复操作不能并发派发；离开、隐藏或最小化取消动画及后续任务。
- 改变窗口、目录、查找栏、字号、正文宽度或模式后，以章节/正文块/Unicode字符锚点恢复；可见段落按实际文字区域判定，不能用跨页段落边框代替文字；页码和像素偏移不作为持久阅读位置。测量使用实际小数像素宽度，避免多页累计偏移。
- 正文分块按需接续并有界保留，在到达传输边界前补齐后续内容，避免半空页和文字跳失；只保留当前窗口需要的图片与观察订阅。迟到结果不得修改非活动阅读状态。

## 紧凑操作与参数弹层

- 内容工具栏使用图标模式时，返回统一为左箭头，展开列表使用列表图标，集合成员开关使用五角星；图标按钮不重复显示文字，保留明确可访问名称、悬停提示及键盘入口。实心/空心和aria-pressed表达已加入/未加入，忙碌只归对应写入；失败保留已确认状态，不自动重试。
- 需要选择输入文件及解析参数的操作先打开参数弹层，原生文件选择由弹层内明确按钮触发，确认前不执行导入。参数不占常驻列表工具栏；取消和Esc不产生写入，页面暂停或离开时关闭弹层，并隔离迟到选择结果。
- 参数弹层复用公共dialog-surface样式及原生dialog焦点隔离，关闭后恢复触发控件焦点；标题、关闭入口、当前文件和必要参数保持紧凑。既有覆盖层复用相同表面和遮罩样式，业务专属尺寸和内容仍由所属组件负责。

## 最近访问列表

- 最近访问与收藏集合分别展示，共用条目外观与阅读入口，各自保留筛选及滚动位置。最近访问按最近打开排序，同一对象只显示一条；收藏状态不限制访问记录的展示。
- 保留数量归当前功能专属设置，变更确认后按最新优先裁剪；裁剪仅影响访问列表，不删除内容副本、收藏或阅读位置，保存失败保留已确认状态。

## 内容标题

- 正文自带与当前目录标题匹配的完整标题或连续分行标题时，复用正文中的标题，不额外生成一份。匹配只忽略空白及零宽排版字符，保留正文块、原文和定位锚点；未匹配时仍显示目录标题。
