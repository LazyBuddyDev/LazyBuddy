# Web 宿主集成

当前默认宿主为 Tauri 2 / Svelte 5 / TypeScript；源码集中于 apps/desktop，Rust 入口位于 src-tauri。旧 Iced 程序、补丁 vendor 和原生 GPU 消费者已删除，不保留原型/生产双入口。

宿主用 module-manager 注册表启动明确的服务包，通过 service-client 私有持久会话调用 API。新闻偏好/缓存仍归独立新闻服务。红果服务提供受控回环压缩媒体资源，WebView2 负责解码和同步；不传逐帧像素，不加载原生共享纹理。资源地址只存在私有会话和 video 元素中。

功能/设置是平级页面，返回均回当前根页面。非当前根页面、全局设置及隐藏窗口不发内容请求；新闻用代数隔离迟到回复，批次最多四来源。红果离开释放会话，隐藏卸载 video.src 并暂停资源读取，恢复不自动播放。托盘与全局热键不依赖内容页生命周期。

全局主题、置顶、根页面、窗口与快捷键保存至 web-preferences.json；新闻设置调用独立 API。红果直连只修改其服务子进程环境，不修改系统代理。已收藏使用黄底实心星，乐观反馈和官方确认分离。

生产红果沿用已验收的 shell-preview 安全存储作用域和数据位置，不导出或迁移密钥。隔离测试使用独立目录，云端进度写入仍关闭。此前用户逐项授权的收藏取消/加回均经手机端确认并恢复原状态，迁移不重复执行这些写入。

当前在线目录中的红果 0.1.0 属于旧原生路线，Web 需要 0.2.1 以上浏览器包（当前 0.2.5）。本次是源码替换，不上传安装包、签名目录或软件正式版。Web 更新源独立于旧安装包，待签名发布后启用实际分发。

偶发真实起播重定向失败的根因仍未确定。底部详情、脱敏轮转日志和手动重试入口保留；不放宽 HTTPS/CDN 来源或绕过权限，不把可重试恢复等同于根因已消除。合成验证与真实节目音画同步、跨显示器 DPI、最终资源预算分别记录于 TASKS.md。
